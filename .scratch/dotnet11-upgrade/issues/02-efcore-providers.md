# 02 — 打通 EF Core 11 的 MySQL 与 SQL Server 数据访问

What to build: 使用方在 .NET 11 下通过现有 Girvs 数据库配置与仓储入口访问实际 MySQL、SQL Server，旧目标仍使用原有依赖。

Blocked by: 01 — 建立基线并打通 .NET 11 基础引用链。

Status: ready-for-agent

- [ ] 核验并锁定相互兼容的 EF Core 11 组件与 Microting 11；接受预发布候选，但不静默降级到 EF Core 10。
- [ ] 为新增目标补齐数据库依赖和必要适配，不改变原目标的依赖选择与公共配置契约。
- [ ] 通过公共配置、DbContext 和仓储入口完成实际 MySQL 的查询、写入、异步保存及项目实际支持的延迟加载验证。
- [ ] 验证分表、迁移历史表以及现有 SQL 拦截器处理的特殊索引标识符。
- [ ] 完成实际 SQL Server 数据访问、建表与迁移路径验证。
- [ ] 覆盖空查询结果、无待应用迁移和空迁移集合等关键边界，明确记录新旧版本行为差异。
- [ ] 数据库测试使用可销毁的临时资源，不操作生产数据库，不以 InMemory 结果替代提供程序验收。
- [ ] 保存可复现的依赖组合、测试命令、成功或失败结果。
