## 依赖说明

本任务包含引用 EF Core 模块的现有跨模块测试，要求 EF Core 11 依赖与编译引用链可用。用户明确要求所有库继续增加 .NET 11 支持，数据库实际读写验收不再作为本任务推进的前置条件。

## 验证结果

17 个库均包含 net11.0 程序集及依赖组，原目标资产保留；整仓干净构建和打包通过。独立包消费者在 .NET 10、11 下成功加载全部 17 个库对应资产和公开类型。

最终全仓双框架回归共 425 项，409 通过、16 失败；失败均是已有 RedisFlowStateStoreTests 的 8 个 Docker 环境依赖用例分别在两框架执行。未将其标为通过，也未为通过测试而删除用例。完整结果见 `../validation-03.md`。
